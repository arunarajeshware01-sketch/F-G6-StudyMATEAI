# StudyMate AI

A full-stack AI study companion built with React, TypeScript, Tailwind CSS, Vercel serverless functions, and Supabase.

## Features
Authentication, personalized profile, dashboard, tasks, AI schedule planner, Pomodoro focus hub, AI Tutor, voice-enabled Feynman Buddy, analytics, achievements, responsive glass UI, and dark/light themes.

## Local setup
1. Install dependencies: `npm install`
2. Configure Vite Supabase variables (`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`).
3. Optionally configure `GEMINI_API_KEY` for model-powered tutor responses; a pedagogical fallback works without it.
4. Run `npm run dev`.

API routes are in `/api`; persistent data is stored in Supabase tables. Deployment is configured for Vercel.
